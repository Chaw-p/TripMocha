사이트맵

TripMocha는 여행 일정 생성과 관리를 중심으로 구성된 웹 서비스로, 사용자가 사이트 내 기능을 직관적으로 탐색할 수 있도록 다음과 같은 구조로 설계되었습니다.

1. 메인 페이지

  • 서비스 소개 및 핵심 기능 안내
  • 여행 검색 진입 버튼
  • 추천 여행 테마 미리보기
  • 로그인 상태에 따른 메뉴 분기

2. 회원 관리

  • 로그인
  • 회원가입
  • 아이디 찾기
  • 비밀번호 재설정
  • 로그아웃

3. 여행 검색 및 추천

  • 여행 지역 검색
  • 여행 기간 설정
  • 여행 인원 선택
  • 여행 테마 선택
  • AI 기반 여행 일정 추천

4. 여행 일정 관리

  • 여행 일정 생성
  • 추천 일정 미리보기
  • 여행 일정 상세 보기
  • 여행 일정 수정
  • 여행 일정 삭제
  • 여행 일정 PDF 저장
  • 지도 기반 경로 시각화

5. 마이페이지

  • 내 정보 조회
  • 내 정보 수정
  • 비밀번호 변경
  • 여행 스타일 설정

6. 고객 안내 및 정책

  • 이용약관
  • 개인정보 처리방침
  • 사이트맵
